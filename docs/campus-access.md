# 校园网访问指南（v1.28.1）

服务器链路：

```
校园网电脑 ──► 主机 192.168.3.173（本机）
                 ├─ :7891 / :8080  (HTTP)  ── netsh portproxy ──► Win10 虚拟机 192.168.201.129:7891
                 └─ :443  / :8443  (HTTPS) ── Node 反向代理  ──► 同一后端
```

端口转发已改为监听 **0.0.0.0**（所有网卡），所以主机换到校园网、插网线、或走 Radmin VPN 都能自动生效；
看护任务每 2 分钟修正一次转发与防火墙（443 / 8443 / 7891 / 8080）。

## 方式一：同一校园网，直接用 IP（最简单）

在浏览器打开：

- `http://<服务器电脑的IP>:7891`（默认，例如 `http://192.168.3.173:7891`）
- 如果 7891 被校园网策略拦了，改用 `http://<IP>:8080`
- HTTPS 端口：`https://<IP>:8443`（自签证书，浏览器会提示，点继续即可）

启动器里的"局域网回退地址"也是这个（`http://192.168.3.173:7891`）。

## 方式二：想用 https://pocket4（每台电脑配置一次）

因为 `pocket4` 没有注册域名，需要让客户端认识它并信任自签证书。服务器上已经放了现成的一键脚本：

1. 在校园网电脑上打开 `http://<服务器IP>:8080/mcl-client-setup.bat`（或在官网点「🌐 校园网配置」）
2. 下载后**右键 → 以管理员身份运行**
3. 输入服务器 IP，脚本会自动：
   - 下载并导入自签证书到"受信任的根证书颁发机构"
   - 写入 hosts：`pocket4` / `pocket4-MCL.com` → 服务器 IP
   - 刷新 DNS 并自检 `https://pocket4/api/status`
4. 之后浏览器直接访问 <https://pocket4>

> 服务器 IP 变了要重新运行一次；证书 10 年有效。

## 方式三：不同网络 / 校园网隔离客户端

如果校园网禁止终端互访（很多学校会开"客户端隔离"），上面两种方式都不通。这时用 **Radmin VPN**：

- 主机已经在 Radmin VPN 里，地址 `26.36.61.205`
- 其它电脑安装 Radmin VPN，加入同一个网络后访问：
  - `http://26.36.61.205:7891`
  - `http://26.36.61.205:8080`
  - `https://26.36.61.205:8443`（浏览器提示证书，选继续）

## 做不到的部分（需要你决定）

- **公网/校外访问**：需要有公网 IP 或域名 + 隧道（Cloudflare Tunnel / frp / 云服务器）。
  当前 `pocket4` 未注册，也没有公网入口，所以只能在校内网或 Radmin 虚拟网内使用。
- **学校路由器端口映射**：需要学校网络管理员权限；本机侧能做的（0.0.0.0 监听、防火墙放行、
  多端口备用）都已经做好。

## 排错

| 现象 | 检查 |
|---|---|
| 完全连不上 | 两台机器是否同一网段：`ping <服务器IP>`；服务器是否开机：`https://pocket4/api/status` |
| 7891 不通但 8080 通 | 校园网拦了 7891，换 8080 |
| 域名打不开 | 是否运行过「校园网配置」；`ipconfig /flushdns`；hosts 里的 IP 是否最新 |
| 证书警告 | 证书是否导入"受信任的根证书颁发机构"，或改用 `http://<IP>:8080` |
| 服务器在线但页面 502 | 虚拟机没开机/服务器没运行：主机上跑 `tools/server_watchdog.ps1` |
